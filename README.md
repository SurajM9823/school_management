# School management system

React/TypeScript frontend in `school/`; Django REST Framework backend in `backend/`.

Start with the [project handover](docs/README.md). It covers the implementation status, frontend/backend integration gaps, developer setup, risks, and a work plan for two developers.

This repository contains substantial UI and backend code, but several screens still use sample data. Source presence is not evidence that a workflow is production ready.

The older [teacher integration note](README_TEACHER_INTEGRATION.md) is useful background; use the handover for the current audit and known limitations.
